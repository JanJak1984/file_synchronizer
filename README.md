### О проекте
Проект создан для автоматической синхронизации файлов с папки (директории) на яндекс диск.

### Быстрый старт
Для быстрой настройки необходимо выполнять действия по пунктам:
1) Зарегистрироваться в яндекс и получить токен для доступа (см. п.3 ([Получение токена](#получение-токена)))
2) Скачать проект себе на компьютер
3) Рекомендуется установить виртуальное окружение и активизировать его
4) Установить зависимости, указанные в файле requirements проекта
5) Переименовать файл шаблона .env_template в .env
6) Ввести настройки проекта в .env (ввести свой токен, указать путь в яндекс-диске в которую 
  будут помещаться синхронизируемые файлы, указать полный путь до папки на жестком диске, где будут
   находиться синхронизируемые файлы)
7) Запустить программу командой `python main.py`

### Получение токена
Чтобы получить токен от yandex следует выполнить несколько пунктов:
1) Зарегистрироваться в yandex
2) Перейти на https://oauth.yandex.ru, создать приложение для доступа к API и отладке, 
В правах задать чтение и запись яндекс диска
3) После создания приложения появятся данные ClientID и Client secret
4) Открыть в браузере https://oauth.yandex.ru/authorize?response_type=code&client_id=CLIENT_ID 
(вместо CLIENT_ID в ссылке ввести свой ClientID). После этого появится код подтверждения, его следует также запомнить
5) В командной строке консоли на ПК ввести:
 ```
  curl -X POST https://oauth.yandex.ru/token \
  -d "grant_type=authorization_code" \
  -d "code=ВАШ_КОД_ПОДТВЕРЖДЕНИЯ" \
  -d "client_id=ВАШ_ClientID" \
  -d "client_secret=ВАШ_Client_secret" 
  ```
6) В ответ должен прийти в том числе access_token, который и должен использоваться в приложении
### Состав проекта
Проект состоит из:
1) Пакет disk, в котором хранятся модули для работы с файлами, которые необходимо синхронизировать
2) Пакет log_settings содержит модули для работы с логером
3) Папка logs (создается при запуске) хранит логи
4) Пакет remote_disk содержит модули для работы с файлами, хранящимися на Яндекс-диске
5) Модуль environs.py содержит функции для работы с переменным окружением
6) Файл env_tepmplate - шаблон для данных переменного окружения
7) Файл requirements - файл зависимостей
8) Файл main.py-основной файл программы
